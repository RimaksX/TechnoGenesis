# Контур

Технологический мод для Minecraft (NeoForge 1.21.1): промышленная металлургия, химическая переработка и энергетика.
Чем глубже переработка руды, тем больше металла вы получаете из одной единицы сырья (×2 → ×12), но тем дороже
оборудование, энергия и реагенты.

## Состояние: этап 1 («фундамент» и ступень ×2)

Реализовано:

- **12 месторождений** (боксит, гарниерит, вольфрамит, хромит, пиролюзит, кобальтит, молибденит, рутил, графит,
  галит, самородная сера, сподумен): обычные и глубинные варианты, сера есть и в Нижнем мире. Высоты, биомы, размер
  и частота жил заданы в `data/kontur/worldgen` и биомных тегах.
- **8 новых металлов** (слитки и блоки), 4 формы переработки для каждого из 11 металлов (дроблёная, промытая руда,
  концентрат, хвосты R1) с идентификатором целевого металла.
- **Ступень ×2**: щёковая дробилка → вращающийся промывочный барабан → магнитно-плотностной сепаратор →
  концентрат (2 шт.) + хвосты R1 (сохраняются для ступени ×3). Суммарно 4 000 FE на единицу сырья (1 200 + 1 000 + 1 800).
- **Водный контур**: промывка → загрязнённая вода → отстойник → техническая вода → промывка (с потерями; нужна подпитка).
- **Энергия**: твердотопливный генератор 48 FE/t (1 уголь ≈ 9 600 FE, золу некуда деть - машина останавливается),
  углеродный конденсатор 400 000 FE, медный провод 32 FE/t. Кабельная сеть переносит FE не быстрее самого слабого
  кабеля, не создаёт и не теряет энергию.
- **Ядро машин**: настройка сторон для предметов/жидкостей/энергии, авто-вывод, подключение к трубам и воронкам других
  модов через capability, диагностика состояния («заполнен выход предметов», «ожидание энергии» и т. д.),
  безопасная остановка без потерь, сохранение содержимого.
- Рецепты машин хранятся в JSON (`data/kontur/recipe/{crushing,washing,separating,settling}`), баланс правится без кода.

План следующих этапов: ×3 (кислота, выщелачивание, фильтр-пресс), ×5 (экстракция, электролиз, регенерация),
×8 (аттритор, автоклав, пар/давление), ×12 (вакуум и плазма), газы и трубы, контроллер линии, остальные генераторы
и кабели, сталь и сплавы, термоядерная энергетика.

## Сборка

Требуется JDK 21.

```bash
./gradlew build          # jar в build/libs
./gradlew runClient      # запуск клиента
./gradlew runServer
```

Для сборки нужны репозитории NeoForge, Mojang, ParchmentMC и `maven.blamejared.com` (API JEI).

## Просмотр рецептов (JEI)

Если установлен [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) (версия 19.19 и новее), в нём появляются
четыре категории: дробление, промывка, сепарация и отстойник. Каждая показывает входы (предмет и/или жидкость), выходы
с шансами, энергию цикла и время. Машины Контура указаны как катализаторы, а клик по стрелке прогресса в интерфейсе
машины открывает её рецепты. Без JEI мод работает как обычно.
